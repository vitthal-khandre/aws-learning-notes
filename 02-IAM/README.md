# Identity and Access Management (IAM)

## What is IAM?

AWS Identity and Access Management (IAM) is a service that helps you securely control access to AWS resources.

Using IAM, you can:

- Create users
- Create groups
- Assign permissions
- Control access to AWS services
- Improve account security

IAM is one of the first AWS services you should learn because every AWS environment depends on secure access management.
