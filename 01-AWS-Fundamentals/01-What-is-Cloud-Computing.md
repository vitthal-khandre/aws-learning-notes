# What is Cloud Computing?

## Definition

Cloud Computing is the delivery of computing services over the Internet instead of owning and maintaining physical servers.

These services include:

- Servers
- Storage
- Databases
- Networking
- Software
- Analytics
- Artificial Intelligence

Instead of buying hardware, you rent the resources only when you need them.

---

### Traditional IT

────────────

Laptop

    │

 ├── Server
 ├── Storage

 └── UPS

### Cloud Computing

```
Your Laptop

      │ Internet
      ▼

| AWS Cloud      |
| Azure          |
| Google Cloud   |
+----------------+
```

You rent everything online.

## Real-Life Example

Imagine you want to open a website.

### Without Cloud

You need to buy:

- Computer Server
- UPS
- Internet
- Cooling
- Rack
- Network Devices

Cost:
- High upfront investment
- Maintenance required

---

### With AWS

Create an EC2 server.

AWS provides:

- Hardware
- Internet
- Power
- Cooling
- Security
- Maintenance

You only pay for what you use.

## Benefits of Cloud Computing

### 1. Pay as You Go

Only pay for the resources you use.

Example:

Instead of buying a server for years,
rent one only for the hours you need.

---

### 2. Scalability

Increase or decrease resources anytime.

Example:

```
100 Users
↓

Launch Bigger Server

↓

1000 Users
```

---

### 3. High Availability

Applications stay online even if one server fails.

---

### 4. Global Access

Deploy applications worldwide using AWS Regions.

---

### 5. Security

AWS provides physical security and many security features.
